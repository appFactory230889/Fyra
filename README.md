# Fyra — landing page

Página estática (HTML + CSS puro, sin JS, sin build) lista para GitHub Pages.

## Archivos
- `index.html` — la página
- `styles.css` — todos los estilos
- `logo.png` — tu logo real de Fyra

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub (público), por ejemplo `fyra-landing`, en una carpeta **separada** de tu proyecto de Android Studio.
2. Sube estos 3 archivos a la raíz del repo.
3. Entra a **Settings → Pages** del repo.
4. En "Source" elige la rama `main` y la carpeta `/ (root)`, luego **Save**.
5. En 1-2 minutos tu sitio queda publicado en `https://<tu-usuario>.github.io/fyra-landing/`. Esa es la URL que pones en el campo "Sitio web" de la Página de Facebook y en el botón "Más información".

## Ya actualizado con tu marca real
- Logo y colores tomados de tu ícono de Fyra (morado/orquídea sobre fondo oscuro, acentos crema/dorado).
- Los 3 enlaces ya apuntan a tu Página de Facebook real.
- La tarjeta de "La Heredera Perdida" usa una portada tipográfica (sin ilustración de stock) para que combine con tu identidad.

## Pendiente para cuando llegue el momento
- El botón "Muy pronto en Google Play": cuando tu app ya esté pública, cámbialo por un `<a>` con el enlace real a la ficha de Play Store.
- Si rehacen la portada/banner de la Página de Facebook, dime y actualizo la paleta de la página si cambia mucho.

## Dominio propio (opcional, más adelante)
GitHub Pages admite un dominio propio gratis (solo pagas el dominio, ~$10-15/año): agregas un archivo `CNAME` con tu dominio y apuntas un registro DNS tipo CNAME a `<tu-usuario>.github.io`. Si quieres, te ayudo con eso cuando llegues a ese punto.
